# Student Grade Manager 

## Overview
Student Grade Manager is a simple React application that displays student records and allows users to search and filter students. It provides an easy way to view student information and identify students based on their academic performance.

## Features
- **Student Cards:** Displays each student's name, age, course, grade, and performance status.
- **Search:** Search for students by name.
- **Performance Filter:** Filter students by all students, passed, or failed.
- **Responsive Design:** Uses Bootstrap to create a responsive card layout.

## Technologies Used
- React
- JavaScript
- Bootstrap

## Concepts Practiced
- React components and props
- `useState` for managing state
- Array methods: `map()`, `filter()`, and `includes()`
- Ternary operators
- Event handling
- Conditional rendering

## Installation and Setup

1. Clone the repository
2. Open the project folder in your terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
